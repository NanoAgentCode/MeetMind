# 第一阶段功能说明

## 完成范围

1. 上传 MP3、WAV、M4A、WEBM、MP4、MPEG、OGG 录音，校验类型、空文件和大小。
2. 调用可配置 ASR 适配器生成转写文本。
3. 使用 LangGraph 编排纪要生成，输出摘要、关键要点、决策和行动事项。
4. 在同一工作区对生成内容进行人工修改并保存定稿。
5. 将定稿导出为 Word 或 Markdown 文件。

## RustFS 对象布局

```text
huizhi-meetings/
├── recordings/{meeting_id}/source.{ext}
├── meetings/{meeting_id}.json
└── exports/{meeting_id}/minutes.{docx|md}
```

后端通过 RustFS 的 S3 兼容接口访问对象，强制使用 path-style addressing。首次写入时自动创建存储桶。

## 状态流转

```text
uploaded → transcribed → generated → edited → export
```

只有保存人工定稿后才允许导出，避免将未经确认的 AI 内容当作正式纪要。

## 接口

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/api/meetings` | 上传录音并创建会议 |
| POST | `/api/meetings/{id}/transcribe` | 执行语音转写 |
| POST | `/api/meetings/{id}/minutes/generate` | 生成结构化纪要 |
| PUT | `/api/meetings/{id}/minutes` | 保存人工定稿 |
| GET | `/api/meetings/{id}/export?format=docx|md` | 导出定稿 |
